# Tahsin'in Müzik Listesi - Flask Podcast App

Bu proje, bir üniversite ödevi kapsamında geliştirilmiş, Flask tabanlı bir müzik/podcast dinleme uygulamasıdır.

## 🚀 Özellikler
- **Canlı Arama:** Sayfa yenilenmeden anlık arama motoru.
- **Modern Arayüz:** Spotify tarzı karanlık tema ve yeşil ses dalgası animasyonları.
- **OOP Mimari:** Python sınıfları ile düzenli veri yönetimi.

## 🛠️ Kurulum
1. `python app.py` komutuyla sunucuyu başlatın.
2. `http://127.0.0.1:5000` adresine gidin.
